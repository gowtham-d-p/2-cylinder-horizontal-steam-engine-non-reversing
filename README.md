# 2-Cylinder Horizontal Steam Engine (Non-Reversing)

## Project Overview

This project focuses on the 3D CAD design and assembly of a two-cylinder horizontal non-reversing steam engine. The design demonstrates the conversion of reciprocating piston motion into rotary motion using a crankshaft and connecting-rod mechanism.

The project aims to develop an understanding of mechanical components, assembly relationships, and the working principles of a reciprocating steam engine.

## Project Objectives

- Develop a 3D CAD model of a two-cylinder horizontal steam engine.
- Understand the mechanism for converting reciprocating motion into rotary motion.
- Study the arrangement of cylinders, pistons, connecting rods, and crankshaft.
- Understand the function of the flywheel and supporting frame.
- Improve mechanical design and assembly modelling skills.

## Working Principle

In a conventional steam engine, steam pressure acts on the pistons inside the cylinders, producing reciprocating motion. The connecting rods transmit this motion to the crank mechanism, which converts it into rotary motion at the crankshaft.

The two-cylinder arrangement provides successive power strokes according to the engine's crank configuration and valve timing. The non-reversing configuration is intended for operation in one rotational direction.

## Main Components
